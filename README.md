# Precision Forge

Redesign the website as a unique, premium and highly professional product-based company website.

Use https://www.metluckgroup.com/ only as general inspiration for corporate structure. Do not copy its UI, layout, colors or components.

Tech

React + TypeScript + Vite + Tailwind CSS + Framer Motion.

Visual Direction

Create a sophisticated luxury industrial / premium engineering brand aesthetic.

The website should feel:
Established • Innovative • Precise • Premium • Confident • Global

Avoid generic corporate/SaaS UI.

Unique UI Style

Use:

Off-white / warm ivory background

Deep charcoal typography

One elegant accent color (deep navy / dark green / bronze)

Oversized editorial typography

Asymmetric layouts

Large cinematic product photography

Thin technical grid lines

Minimal borders

Strong whitespace

Large numbered sections

Subtle architectural/technical visual elements

Avoid:

Excessive cards

Excessive rounded corners

Generic blue corporate theme

Glassmorphism

Bright gradients

Huge shadows

Stock-template appearance

Header

Minimal transparent header over hero.

Logo on left.

Navigation:
Home / About / Products / Industries / Capabilities / Projects / Contact

Right:
Let's Talk →

On scroll, transition into an ivory/white header with subtle blur.

Hero

Create a dramatic split/asymmetric hero.

Left:
Small label: ENGINEERED FOR EXCELLENCE

Huge headline:

"Precision That
Moves Industry."

Short premium description.

CTA:
Explore Products →

Right:
Large cinematic product/manufacturing image extending beyond the grid.

Add small technical details such as:
01 / ENGINEERING
02 / PRECISION
03 / PERFORMANCE

Keep it minimal.

Homepage Sections

01 — ABOUT
Large editorial statement + image.

"Engineering products for industries where performance matters."

02 — PRODUCTS
Make products the visual focus.

Use large horizontal product showcases rather than small generic cards.

Each product:
Image → Product name → Category → Arrow

Hover:
Image zoom + subtle text movement.

03 — INDUSTRIES
Use full-width image panels with overlay text.

04 — CAPABILITIES
Create a technical editorial layout with oversized numbers:
01 Engineering
02 Manufacturing
03 Quality
04 Customization

05 — QUALITY
Full dark section with:
"Precision is not an option. It's our standard."

Use technical/product imagery and subtle line graphics.

06 — PROJECTS
Large editorial case-study layouts with varying image sizes.

07 — GLOBAL PRESENCE
Minimal world/global visual with company reach.

08 — CTA
Large typography:

"Let's build what comes next."

CTA: Start a Conversation →

Interaction

Use Framer Motion subtly:

smooth page transitions

text reveal

image reveal

image scale on hover

section fade-up

smooth arrow movement

subtle parallax

Do not animate everything.

Responsive

Make it excellent on desktop, tablet and mobile.

Mobile should retain the premium editorial feel rather than simply stacking desktop cards.

Important

Do not invent company facts.

Use placeholder content/data where required.

Create reusable React components and keep products, industries and projects in separate data files.

The final result should look like a real premium global engineering/product brand, not a standard corporate website or AI-generated template.
